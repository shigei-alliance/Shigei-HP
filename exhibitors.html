出品方法・パターン

平面・立体作品問わず出品可能です。ご自身の状況に合わせて、以下の3つのパターンから選択してください。

Pattern A

フルDIY

  • 印刷：自分
  • 搬入：自分 (当日持込)
  • 設置：自分

こだわりがある方、当日来場できる方におすすめ。

Pattern B

設置委託

  • 印刷：自分
  • 搬入：郵送/事前手渡し
  • 設置：運営

作品は3/6までに運営へお渡しください。

Pattern C

フル委託 (データ入稿)

  • 印刷：運営代行
  • 搬入：運営
  • 設置：運営

注意

データ提出期限：4/2 (土)
印刷代が別途必要です。
PDFサイズと印刷サイズの一致を確認してください。

表現規制について（エロ・グロNG）

会場の九段ギャラリーは公共施設内にあり、子供も多く利用します。 直接的な性描写はもちろん、肌の露出が多い作品も展示NGとなる可能性があります。 過去に展示不可となった事例もありますので、十分ご注意ください。

生成AIの利用について

本展覧会では、原則として出品者自身の手によって制作された作品に限ります。

  • NG：生成AI出力物をそのまま、または加工して利用した作品
  • OK：構図や配色の参考としてAIを利用し、手で描き直した作品
